# Stock Monitor

מערכת מעקב מניות בזמן אמת: התראות לטלגרם, דשבורד ווב, ניתוח AI מבוסס Claude
ומעקב תיק אישי — עם שמירת נתונים ב-PostgreSQL.

## יכולות

- **ניטור בזמן אמת** — סריקת המניות ברשימת המעקב, התראות על שינויי מחיר,
  זינוקי נפח (מותאמים לשעת המסחר) ומועדי דוחות.
- **בוט טלגרם** — התראות אוטומטיות + בוט פקודות: שליחת טיקר מחזירה נתונים
  מלאים, `ניתוח AAPL` מחזירה ניתוח AI, `/status` מציגה את כל המעקב.
- **ניתוח AI אישי** — כשמניה נמצאת בתיק שלך, הניתוח משווה את הרווח/הפסד
  בפועל ממחיר הכניסה מול התמונה הטכנית היום, ונותן המלצה מותאמת לנקודת
  הכניסה שלך במקום דירוג גנרי.
- **דשבורד** — מעקב חי, התיק שלי, חשיפת תנודתיות (ATR), פיזור סקטוריאלי
  ותרשימי עוגה לפי סקטורים ומדדים.
- **Webhooks** — קבלת התראות מ-TradingView.

## הרצה מקומית

```powershell
pip install -r requirements.txt
copy .env.example .env      # ואז מלא את הערכים
python run.py
```

הדשבורד: http://localhost:8080

ללא `DATABASE_URL` המערכת רצה כרגיל עם נתונים בזיכרון בלבד — נוח לפיתוח,
אבל היסטוריית ההתראות והתיק נמחקים בכל הפעלה מחדש.

## שמירת נתונים ב-PostgreSQL

הגדרת `DATABASE_URL` מפעילה התמדה מלאה. הטבלאות (`alerts`, `holdings`)
נוצרות אוטומטית בהפעלה הראשונה — אין צורך במיגרציות ידניות:

```
DATABASE_URL=postgresql://user:password@host:5432/stocktracker
```

מקבלים DB חינמי מ-Render, Supabase או Neon. כל צורות ה-URL שהם מספקים
נתמכות (`postgres://`, `postgresql://`, `postgresql+psycopg://`).

אם החיבור נכשל — המערכת רושמת שגיאה בלוג וממשיכה לרוץ בזיכרון במקום
לקרוס, כך שתקלה ב-DB לא מפילה את הניטור ואת התראות הטלגרם.

## פריסה חינמית (כתובת יציבה מכל מכשיר)

## הגנת סיסמה על הדשבורד

הגדרת שני משתני הסביבה הבאים מפעילה HTTP Basic Auth על הדשבורד, ה-API
ו-`/docs`. כשהם לא מוגדרים אין דרישת התחברות, כך שהרצה מקומית לא מושפעת:

```
DASHBOARD_USER=myname
DASHBOARD_PASSWORD=some-long-password
```

**חובה בכל פריסה ציבורית** — אחרת כל מי שמגיע לכתובת רואה את התיק ויכול
להריץ ניתוחי AI על חשבון ה-API שלך.

שני נתיבים נשארים פתוחים בכוונה: `/health` (יעד הפינג ששומר על השירות ער,
מחזיר רק חותמת זמן) ו-`/webhook/*` (TradingView, מוגן בחתימת HMAC נפרדת).

בוט הטלגרם מוגן בנפרד — הוא עונה רק ל-`TELEGRAM_CHAT_ID` שהוגדר.

## מבנה

| קובץ | תפקיד |
|---|---|
| `stock_monitor/db.py` | שכבת PostgreSQL (SQLAlchemy) — טבלאות `alerts` ו-`holdings` |
| `stock_monitor/store.py` | `AlertStore` ו-`PortfolioStore` — DB עם נפילה חזרה לזיכרון |
| `stock_monitor/portfolio_risk.py` | ATR, חשיפת תנודתיות, ריכוזיות סקטוריאלית וחלוקת התיק |
| `stock_monitor/dashboard.py` | דשבורד + API של התיק (הוספה/עריכה/מחיקה) |
| `stock_monitor/telegram_bot.py` | בוט הפקודות בטלגרם |
| `stock_monitor/notifier.py` | שליחת התראות: טלגרם, דיסקורד, דסקטופ |
| `stock_monitor/ai_analyst.py` | ניתוח Claude, כולל הזרקת הפוזיציה האישית |
| `stock_monitor/alert_engine.py` | כללי ההתראות על מחיר ונפח |
| `stock_monitor/data_feed.py` | שליפת נתונים מ-yfinance וזיהוי סשן המסחר |
| `stock_monitor/main.py` | חיווט כל המערכת והרצה כדימון |
