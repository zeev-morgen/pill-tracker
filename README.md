# Stock Monitor

מערכת מעקב מניות בזמן אמת: התראות לטלגרם, דשבורד ווב, ניתוח AI מבוסס Claude
ומעקב תיק אישי — עם שמירת נתונים ב-PostgreSQL.

## יכולות

- **ניטור בזמן אמת** — סריקת המניות ברשימת המעקב, התראות על שינויי מחיר,
  זינוקי נפח (מותאמים לשעת המסחר) ומועדי דוחות.
- **בוט טלגרם** — התראות אוטומטיות + בוט פקודות, הכול בעברית. מתחת לשורת
  ההקלדה יש תפריט כפתורים קבוע: *התיק שלי*, *מעקב*, *חדשות*, *סיכום*,
  *התראות* ו*עזרה*. שליחת טיקר (כולל `ESLT.TA`) מחזירה נתונים מלאים
  במטבע שבו המניה נסחרת, ו-`ניתוח AAPL` מחזירה ניתוח AI.
- **סיכום יומי בטלגרם** — פעם ביום, 45 דקות אחרי הסגירה (`digest_time`),
  נשלחת תמונת מצב אחת: שווי התיק, הרווח/הפסד, התנועות הגדולות, אזהרות
  ריכוזיות וכותרות חדשות. בלי לבקש.
- **השתקת התראות מתוך הטלגרם** — לכל התראה שני כפתורים: ניתוח AI, או
  השתקת המניה לשעה. מסך *התראות* מציג מה מושתק ועד מתי, מה נשלח לאחרונה,
  ומאפשר השתקה גורפת לשעה או עד למחרת. השתקה היא תמיד דדליין, לא מתג —
  כדי שלא תישאר דלוקה בלי שתשים לב.
- **ניהול מניות מתוך הטלגרם** — מסך *⚙️ ניהול מניות*: כל מניה במעקב עם
  כפתור ❌ להסרה, כפתור ➕ להוספה, ולכל שורה גם כללי ההתראה שהיא נמצאת
  תחתיהם (ו-🔧 כשהם מותאמים ב-`config.yaml`). טיקר שלא קיים נדחה עם הסבר,
  אבל כש-Yahoo לא זמין המניה נוספת על סמך מה שנשלח ונאמר שכך — כדי
  שתקלה אצלם לא תחסום הוספה של טיקר תקין. אחרי הסרה יש כפתור ↩️ להחזרה.
  גם בהקלדה: `הוסף AVGO` / `הסר AVGO`.
- **ניתוח AI אישי** — כשמניה נמצאת בתיק שלך, הניתוח משווה את הרווח/הפסד
  בפועל ממחיר הכניסה מול התמונה הטכנית היום, ונותן המלצה מותאמת לנקודת
  הכניסה שלך במקום דירוג גנרי.
- **ניתוח AI של התיק כמכלול** — כפתור בטאב "התיק שלי" ששולח את כל
  הפוזיציות, ה-ATR, הפיזור הסקטוריאלי והחשיפה למדדים לניתוח אחד: ריכוזיות,
  רמת סיכון, מובילים וגוררים והמלצות פעולה מדורגות. זמין גם מהטלגרם.
- **ניתוח AI לכל מניה בתיק** — כפתור 🧠 בכל שורה בטבלה, עם המלצה המותאמת
  למחיר הכניסה שלך באותה מניה.
- **יומן מסחר** — כפתור 💵 בכל שורה רושם מכירה (מלאה או חלקית). המערכת
  מחשבת רווח/הפסד, זמן החזקה ו-ATR בעת המכירה, ושומרת את הכל ב-DB.
  לכל עסקה סגורה אפשר לבקש דירוג מ-Claude — רמזור אדום/כתום/ירוק עם הסבר
  מילולי שמדרג את **איכות ההחלטה**, לא את גודל הרווח — ולצדו שדה פתוח
  לחוות דעת אישית משלך.
- **חדשות מתפרצות** — טאב ייעודי לכותרות על המניות שבתיק, וגם בטלגרם.
  נסרק אוטומטית כל יום ב-09:00 ET, חצי שעה לפני פתיחת המסחר, ונשמר במטמון
  כדי שהטאב ייפתח מיידית. הכותרות נשלפות משלושה מקורות בטור (yfinance,
  חיפוש Yahoo, ו-RSS), כי **תשובה ריקה אינה תשובה**: באוקטובר 2026 Yahoo
  סגרה את הנתיב שממנו yfinance שלפה חדשות, והספרייה החזירה רשימה ריקה
  בלי שגיאה — כך שבמשך חודש הניתוחים פשוט לא כללו חדשות ולא אמרו זאת.
  כשאף מקור לא עונה, המערכת אומרת במפורש "מקור החדשות אינו זמין" במקום
  להציג יום שקט. `/api/diagnostics/news` מדווח איזה מקור עונה ואיזו גרסת
  yfinance רצה בפועל.
- **רשימת מעקב הניתנת לעריכה** — הוספה והסרה של מניות ישירות מעמוד המעקב,
  בלי לערוך `config.yaml` ובלי הפעלה מחדש. `config.yaml` משמש כזריעה
  ראשונית בלבד; מרגע שיש עריכה, הרשימה שבמסד היא הקובעת.
- **נתוני פרי/פוסט מרקט** — עמודה ייעודית בטבלת התיק עם המחיר והשינוי
  במסחר המוקדם/המאוחר, לצד ימי ההחזקה של כל פוזיציה.
- **דשבורד** — מעקב חי, התיק שלי, יומן מסחר, חדשות מתפרצות, חשיפת תנודתיות
  (ATR), פיזור סקטוריאלי ותרשימי עוגה לפי סקטורים ומדדים.
- **Webhooks** — קבלת התראות מ-TradingView.

## הרצה מקומית

```powershell
pip install -r requirements.txt
copy .env.example .env      # ואז מלא את הערכים
python run.py
```

הדשבורד: http://localhost:8080

ללא `DATABASE_URL` המערכת רצה כרגיל עם נתונים בזיכרון בלבד — נוח לפיתוח,
אבל היסטוריית ההתראות והתיק נמחקים בכל הפעלה מחדש.

## שמירת נתונים ב-PostgreSQL

הגדרת `DATABASE_URL` מפעילה התמדה מלאה. הטבלאות (`alerts`, `holdings`,
`closed_positions`, `watchlist`) נוצרות אוטומטית בהפעלה הראשונה, ועמודות
שנוספו בגרסאות מאוחרות מתווספות לטבלה קיימת — אין צורך במיגרציות ידניות:

```
DATABASE_URL=postgresql://user:password@host:5432/stocktracker
```

מקבלים DB חינמי מ-Render, Supabase או Neon. כל צורות ה-URL שהם מספקים
נתמכות (`postgres://`, `postgresql://`, `postgresql+psycopg://`).

אם החיבור נכשל — המערכת רושמת שגיאה בלוג וממשיכה לרוץ בזיכרון במקום
לקרוס, כך שתקלה ב-DB לא מפילה את הניטור ואת התראות הטלגרם.

## פריסה חינמית (כתובת יציבה מכל מכשיר)

מדריך מלא שלב-אחר-שלב: **[DEPLOY.md](DEPLOY.md)**.

בקצרה — Neon (בסיס נתונים) + Render (הרצה) + UptimeRobot (שמירה על השירות
ער), שלושתם חינמיים. הריפו כולל `render.yaml` מוכן.

## הגנת סיסמה על הדשבורד

הגדרת שני משתני הסביבה הבאים מפעילה HTTP Basic Auth על הדשבורד, ה-API
ו-`/docs`. כשהם לא מוגדרים אין דרישת התחברות, כך שהרצה מקומית לא מושפעת:

```
DASHBOARD_USER=myname
DASHBOARD_PASSWORD=some-long-password
```

**חובה בכל פריסה ציבורית** — אחרת כל מי שמגיע לכתובת רואה את התיק ויכול
להריץ ניתוחי AI על חשבון ה-API שלך.

שני נתיבים נשארים פתוחים בכוונה: `/health` (יעד הפינג ששומר על השירות ער,
מחזיר רק חותמת זמן) ו-`/webhook/*` (TradingView, מוגן בחתימת HMAC נפרדת).

בוט הטלגרם מוגן בנפרד — הוא עונה רק ל-`TELEGRAM_CHAT_ID` שהוגדר.

## מבנה

| קובץ | תפקיד |
|---|---|
| `stock_monitor/db.py` | שכבת PostgreSQL (SQLAlchemy) — `alerts`, `holdings`, `closed_positions`, `watchlist` |
| `stock_monitor/store.py` | הסטורים (התראות, תיק, יומן מסחר, מעקב) — DB עם נפילה חזרה לזיכרון |
| `stock_monitor/portfolio_risk.py` | ATR, חשיפת תנודתיות, ריכוזיות סקטוריאלית, חלוקת התיק ונתוני פרי/פוסט |
| `stock_monitor/news.py` | שליפת כותרות משלושה מקורות בטור, עם דיווח מי ענה |
| `stock_monitor/news_monitor.py` | סריקת חדשות יומית על המניות שבתיק |
| `stock_monitor/messages.py` | נוסח ההתראות בעברית (כולל כיווניות ומטבע) |
| `stock_monitor/mute.py` | השתקת התראות לזמן מוגדר, מתוך הטלגרם |
| `stock_monitor/reference_data.py` | טבלת סקטורים וקרנות סל מאומתת, כגיבוי ל-yfinance |
| `stock_monitor/dashboard.py` | דשבורד + API של התיק, יומן המסחר, המעקב והחדשות |
| `stock_monitor/telegram_bot.py` | בוט הפקודות בטלגרם |
| `stock_monitor/notifier.py` | שליחת התראות: טלגרם, דיסקורד, דסקטופ |
| `stock_monitor/ai_analyst.py` | ניתוח Claude, כולל הזרקת הפוזיציה האישית |
| `stock_monitor/alert_engine.py` | כללי ההתראות על מחיר ונפח |
| `stock_monitor/data_feed.py` | שליפת נתונים מ-yfinance וזיהוי סשן המסחר |
| `stock_monitor/main.py` | חיווט כל המערכת והרצה כדימון |
